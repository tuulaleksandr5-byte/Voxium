# Voxium — готовая сборка для Windows x64

[Скачать ZIP](Voxium-Windows-x64.zip?raw=true)

Распакуйте архив и запустите `Voxium.exe`. Нужны Windows 10/11 x64 и графический драйвер Vulkan/DirectX 12. Если обычный запуск не открывает окно, попробуйте `Start-Vulkan.bat`.

В сборке есть рабочий верстак 3×3, печь с топливом и переплавкой железа/золота, а также подключённые текстуры из пользовательского набора. Мобов в этой версии нет.

Содержимое инвентаря и печей, топливо и прогресс переплавки пока сбрасываются при перезагрузке мира. Блоки мира сохраняются.

Windows x64 EXE собран из текущих изменений; 270 тестов исходников прошли. Крафт и плавка проверены в Linux-клиенте. Запуск этой Windows-сборки на настоящем Windows-компьютере не проверен.
