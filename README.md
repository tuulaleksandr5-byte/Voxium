# Voxel Sandbox Rust

Нативная 3D-песочница на **Rust 1.99.1 + Bevy 0.20.1**, edition 2024.

**Статус: рабочий творческий фундамент (pre-1.0).** В существующем репозитории реализован игровой цикл: меню → создание мира по seed → исследование и строительство → сохранение → повторная загрузка. Это ещё не релиз v1.0: Windows и целевая производительность требуют отдельной проверки.

## Запуск

Установите [Rust через rustup](https://rustup.rs/). Версия и компоненты закреплены в `rust-toolchain.toml`, зависимости — в `Cargo.lock`.

```bash
cargo run --locked -p voxel-client
```

Для более быстрой игры после первой компиляции:

```bash
cargo run --release --locked -p voxel-client
```

На Debian/Ubuntu нужны `pkg-config`, `libasound2-dev`, `libudev-dev`, `libwayland-dev`, `libxkbcommon-dev`, `libx11-dev`, `libxcursor-dev`, `libxi-dev`, `libxrandr-dev` и Vulkan-драйвер видеокарты. На Windows нужен Rust MSVC toolchain с C++ build tools; Windows GNU x64 EXE собран кросс-компиляцией; меню проверено через Wine/Vulkan, но запуск на настоящей Windows **не проверен**. Подробности: [Windows-сборка](docs/WINDOWS_BUILD.md).

В подготовленной облачной среде перед командами:

```bash
source /workspace/.voxel-env/activate.sh
cd /workspace/voxel-sandbox-rust
cargo run --locked -p voxel-client
```

Для запуска нужен графический дисплей. Headless-тесты ядра обходятся без окна/GPU; инструкции Xvfb для облачной проверки — в [отчёте проверки](docs/VALIDATION.md).

## Управление

| Клавиша | Действие |
|---|---|
| W A S D / мышь | Ходьба / обзор |
| Space | Прыжок |
| Shift | Бег |
| Ctrl | Приседание (под потолком нельзя встать) |
| 1–9 | Выбор слота хотбара |
| E | Каталог блоков: выбрать слот, затем материал |
| ЛКМ / ПКМ | Разрушить / поставить блок на расстоянии до 6 блоков |
| Esc | Пауза / продолжение |
| F5 | Сохранить мир |

Блок нельзя установить внутри игрока. Коренная порода неразрушима. Вода в этом этапе — статические прозрачные блоки, проходимые и доступные для удаления; симуляция течения и плавание не реализованы.

## Реализовано

- Главное меню, ввод имени и необязательного числового seed, список сохранений, пауза.
- Творческий каталог, бесконечные блоки, хотбар на 9 слотов, перекрестие и контур выбранного блока.
- 16 стабильных ID: воздух, трава, земля, камень, глубинный камень, песок, гравий, дерево, листва, доски, булыжник, стекло, вода, коренная порода, снег, песчаник.
- Компактные секции 16×16×16, высоты **−64…320 включительно**, отрицательные координаты.
- Детерминированный noise-ландшафт: равнины, лес, пустыня, горы, океан; деревья, пещеры, вода.
- Фоновая загрузка ближайших чанков и построение мешей, выгрузка дальних чанков, лимит загрузок мешей за кадр.
- Greedy meshing, отсечение скрытых граней и frustum culling Bevy. ECS-сущности соответствуют мешам секций/материалам, а не отдельным блокам.
- Собственные процедурные пиксельные текстуры 16×16, nearest-фильтрация и повторение по объединённым граням; солнце, цикл дня/ночи, туман, простая прозрачность.
- Гравитация, swept AABB-коллизии, 3D DDA, запрет движения в незагруженный чанк.
- Версионированные сохранения: seed, имя, положение/обзор, время и правки блоков. Автосохранение каждые 30 секунд, ручное сохранение и сохранение при выходе.
- Проверка целостности, синхронизированные временные файлы и резервная копия. Повреждённый файл восстанавливается из проверенной копии; несовместимая версия выдаёт ошибку.
- Настройки разрешения, полноэкранного режима, дальности 4–16 чанков, мыши, VSync и общей громкости.

## Сохранения

По умолчанию каталог `saves/` находится относительно рабочей директории запуска. Его можно задать переменной `VOXEL_SAVE_DIR`.

Мир хранится в `<id>.json`, предыдущая проверенная версия — в `<id>.json.bak`. Настройки находятся в `settings.cfg` и не попадают в список миров. Не удаляйте резервные копии при ручном восстановлении. Контрольная сумма обнаруживает повреждение, но не предназначена для защиты от намеренной подделки.

## Проверки

```bash
cargo fmt --all -- --check
cargo check --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
cargo build --locked -p voxel-client
```

Тесты проверяют координаты и границы, детерминированную генерацию, правки/выгрузку чанков, greedy meshing, DDA, коллизии и округление контактов, вставание под потолком, целостность/восстановление сохранений. Сквозной headless-сценарий строит на границе отрицательных чанков, сохраняет, создаёт новый экземпляр мира и проверяет постройку и меш.

## До полноценного v1.0

- Проверка уже собранного Windows GNU x64 EXE на настоящей Windows-машине и подготовка MSVC release-сборки.
- Профилирование на GTX 1660/1920×1080, длительные переходы через чанки и большой объём построек. **60 FPS не измерены и не гарантируются.**
- Масштабирование сохранений большого мира: сейчас сериализация и синхронизация файла выполняются на основном потоке; нужны фоновая запись и региональные данные.
- Floating origin для точности игрока/камеры на очень больших координатах.
- Полировка воды/стекла (сортировка прозрачности по мешу секции может давать артефакты), текстур, теней, интерфейса и русской локализации. Текущий интерфейс на английском.
- Более широкий ручной QA настроек/множества миров, длительная проверка сохранности и внешнее тестирование сборок.

Станки, инструменты, выживание, крафт, механизмы, драконы и мультиплеер не входят в текущий этап. Приложенные изображения служат референсами палитры и материалов; готовые спрайты из них в игру не извлекались.
