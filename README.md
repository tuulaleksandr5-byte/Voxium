# Voxium

**Voxium** — воксельная 3D-игра на Rust и Bevy. Все файлы проекта собраны в одном каталоге: **[game/](game/)**.

В каталоге `game/` находятся код игры, текстуры, звуки, конфигурации, документация и инструменты.

## Запуск

Установите [Rust](https://rustup.rs/), затем выполните из корня репозитория:

```bash
cd game
cargo run --locked -p voxel-client
```

Для оптимизированной сборки:

```bash
cd game
cargo run --release --locked -p voxel-client
```

[Подробная инструкция и управление](game/README.md) · [Документация](game/docs/INDEX.md) · [План разработки](game/docs/ROADMAP.md)

Каталог `.github/` оставлен только для служебных шаблонов и автоматической проверки проекта.
