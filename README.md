# Voxium / Voxel Sandbox — 2.0.0-alpha.4

[Скачать игру и все файлы проекта (ZIP, около71МБ)](https://github.com/tuulaleksandr5-byte/Voxium/raw/refs/heads/download/alpha4-all-files/VoxelSandbox-alpha.4-All-Files.zip)

Распакуйте архив в отдельную папку и запустите **VoxelSandbox.exe**.

Внутри: готовый Windows x64 EXE; все текстуры и действующие настройки; `source/` — полный Rust/Bevy-проект из532файлов; `changes.patch` — полный diff; `BUILD-INFO.json` и `FILE-SHA256.json` — версия и контрольные суммы.

Добавлены добыча по времени, девять блоков, текстуры инструментов/брони, крафт2x2 и четыре руды в новых мирах. Все239PNG сохранены без изменения байтов.251Linux-тест и250Windows-тестов черезWine проходят; реальная Windows-машина не проверена. Скриншоты — в `qa/`.

**Это альфа:** инвентарь/крафт/дроп/сундуки пока сбрасываются при закрытии мира. Обычные постройки и настройки генератора сохраняются. Верстак/печь пока без3x3/плавки; защита/прочность не добавлены. Для точной картинки палки нужен отдельныйPNG — в присланныхZIP его нет.
