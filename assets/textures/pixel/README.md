# Пиксельный набор 32×

Оригинальная графика Voxium, целиком сгенерированная `tools/generate_pixel_art.py`.
Сторонние ресурспаки не использовались.

- `32x32/` — авторское разрешение тайлов блоков.
- `128x128/` — те же тайлы, увеличенные в 4 раза без сглаживания; их встраивает атлас.
- `icons/` — значки предметов 128×128.

Текстуры мобов лежат в `assets/textures/mobs/`, модели — в `assets/data/mob_models.ron`.
Файлы не редактируются вручную: измените генератор и запустите

```bash
python3 tools/generate_pixel_art.py
```
