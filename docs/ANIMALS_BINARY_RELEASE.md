# Voxium Animals — Windows x64 release candidate

> **Статус:** сборка предоставлена отдельно от GitHub, не опубликована как GitHub Release и не включена в исходники `main`.

Обнаружен и проверен архив `Voxium-Animals-Windows-alpha-x64.zip`. Это отдельная Windows-сборка **поверх alpha.4**, а не обновление исходников в репозитории.

## Изменения относительно alpha.4 (по отчёту, включённому в архив)

- Четыре животных: корова, свинья, овца и курица. Оригинальные GLB/анимации, естественный спавн, движение, урон и добыча.
- Ведро с молоком, стрижка и восстановление шерсти, куриные яйца.
- Полное сохранение инвентаря, сундуков, дропа и животных; новый формат сохранений **schema 3**, миграция schema 1/2 с резервной копией.
- Данные животных: `Voxium/assets/data/mobs.ron`.

Включённый `REPORT.md` заявляет 268 прошедших тестов и проверку GUI на Linux. **Мы здесь не повторяли эти тесты**. Исполнение Windows EXE на настоящей Windows не проверено (это явно отмечено в `BUILD-INFO.json`).

## Важные ограничения

1. Архив содержит готовый EXE, настройки и отчёт, **но не содержит Rust-исходники**, реализующие животных и schema 3. Текущая ветка `main` остаётся на alpha.4; данный документ не добавляет животных в собираемую из `main` игру.
2. EXE превышает обычное ограничение GitHub в 100 МБ на отдельный файл, поэтому его **не следует** коммитить в Git.
3. Старый EXE не может читать сохранения schema 3. Перед запуском новой сборки сделайте отдельную резервную копию папки `saves-v2`.
4. Монстры, расширенный крафт и функциональные машины по отчёту пока не включены.

## Как опубликовать ZIP как отдельный GitHub Release

Публикация ещё **не выполнялась**. Скопируйте оригинальный ZIP на компьютер с `gh` (GitHub CLI), выполните вход в аккаунт и команду в каталоге репозитория:

```powershell
gh auth login
gh release create v2.0.0-alpha.animals.1 ".\Voxium-Animals-Windows-alpha-x64.zip" --repo tuulaleksandr5-byte/Voxium --title "Voxium Animals — Windows x64 preview" --notes "Предварительная Windows-сборка животных поверх alpha.4. Перед запуском создайте резервную копию saves-v2: новые сохранения используют schema 3. Исходники Animals пока не слиты в main; сборка не проверена на настоящей Windows." --prerelease
```

Имя тега выше — **предложение**, не существующая подтверждённая версия. Предпочтительно сначала вернуть исходники Animals в ветку, проверить сборку из Git и только после этого выпускать релиз, который соответствует тегу.

## Что требуется для полноценного обновления исходного кода

Получить Rust-проект, соответствующий Windows EXE (в отчёте называются `crates/game_core/src/mobs.rs`, `runtime_save.rs`, `apps/client/src/animals_client.rs` и интеграционные тесты); добавить в репозиторий вместе с GLB-ресурсами; запустить `cargo fmt --all -- --check`, `cargo test --locked --workspace`, `cargo clippy --locked --workspace --all-targets -- -D warnings`, собрать клиент; проверить миграцию сохранений и запуск на Windows. Компилированный EXE не является заменой этих исходников.
