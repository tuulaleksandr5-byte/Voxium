# BASE 1

Основная сохранённая версия Voxium: 79 мобов, блоки и предметы Minecraft 1.20.1, редстоун,
механики природы (падающие блоки, рост культур, листва, бамбук, ламинария), анимация динамита.

Git-метка: `BASE-1` (пробелы в именах меток нельзя). Вернуться к версии:

```bash
git checkout BASE-1
```

Готовая сборка для Windows — `dist/Voxium-Windows-x64.zip` на момент метки.
