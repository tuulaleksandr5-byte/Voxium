# Внесение изменений

1. Открой задачу (Issue) с описанием результата и критерием проверки.
2. Создай ветку `feature/<module>-<task>`.
3. Не ломай публичные интерфейсы соседних модулей без согласования.
4. Добавь или обнови тесты.
5. Локально запусти `cargo fmt --all -- --check`, `cargo check --workspace`, `cargo test --workspace`.
6. Создай Pull Request с результатами проверок и ограничениями.

В текущем bootstrap-коде игровой процесс отсутствует. Не маркируй его как версию 1.0.
