# Творческий инвентарь как в оригинале

Сделано по видео: творческое меню с 12 вкладками, сеткой 9×5 с прокруткой, поиском, рядом быстрого доступа и корзиной.

## Вкладки
| Ряд | Вкладки |
|---|---|
| Верхний | Строительные блоки · Разноцветные блоки · Природные блоки · Функциональные блоки · Редстоун · Поиск предметов |
| Нижний | Инструменты и приспособления · Боевые предметы · Еда и напитки · Ингредиенты · Яйца призыва · Инвентарь выживания |

Все 1394 предмета распределены по вкладкам автоматически (`game_core::creative`): ступеньки и плиты — в строительные, ковры, шерсть, бетон, стекло, флаги, ящики и свечи — в разноцветные, руды, брёвна, цветы, коралл — в природные, верстак, печи, сундуки, таблички — в функциональные, провод, поршни, двери, кнопки — в редстоун; мечи, броня, стрелы — в боевые; лодки, вёдра, вагонетки — в инструменты.

## Механика
| Действие | Результат |
|---|---|
| Наведение на вкладку | подсказка с полным названием |
| Наведение на предмет | название, урон (у оружия и инструментов) и внутренний ID |
| Колесо мыши над сеткой или кнопки ▲ ▼ | прокрутка на ряд; ползунок показывает положение |
| ЛКМ по предмету | полная стопка на курсор |
| ПКМ по предмету | по одному на курсор (добавляется, если там тот же предмет) |
| Shift + ЛКМ | полная стопка сразу в инвентарь |
| ЛКМ по сетке с предметом на курсоре | предмет удаляется |
| Ячейка «Удалить предмет» (✕) | то же самое для предмета на курсоре |
| Вкладка «Поиск» | вводите название (регистр не важен), Backspace стирает |
| Ряд быстрого доступа под сеткой | обычные клики по ячейкам: положить, взять, обменять |
| «Инвентарь выживания» | обычный экран: экипировка, крафт 2×2, рюкзак, быстрый доступ и корзина |

С открытым сундуком, печью или верстаком творческая сетка не показывается, как в оригинале.

## Пока нет
- «Сохранённые панели» (вкладка со сохраняемыми рядами хотбара).
- Выбор слота цифрами 1–9 прямо в меню (слот выбирается вне меню).
