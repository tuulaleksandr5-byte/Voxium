# Мобы: 79 штук по справочнику 1.20.1

Источник: `docs/MOBS_REFERENCE.txt`. Таблица мобов генерируется `tools/generate_mobs.py`
(→ `crates/game_core/src/mob_table.rs`, `apps/client/src/mob_skins.rs`, `tools/mobs.json`),
модели и текстуры — `python3 tools/generate_pixel_art.py`.

Что есть у каждого моба: здоровье, поведение (мирный / нейтральный / враждебный), размер,
урон, дроп из справочника (предметы из каталога), модель с анимацией, текстура, яйцо призыва
и команда `/summon <id>`.

Механики: нейтральные мобы атакуют только после удара; стрелки бьют с расстояния;
крипер взрывается; летающие парят; водные живут в воде; зомби, скелеты, фантомы,
утопленники и зомби-жители горят на солнце.
Естественно появляются: корова, свинья, овца, курица, кролик, лошадь, осёл, лама, лиса,
волк, кошка, коза; ночью — зомби, скелет, паук, крипер, странник Края, ведьма, кадавр, пещерный паук.
Остальные — через яйца и `/summon`.

Не сделано: разведение, приручение, верховая езда, торговля, телепорт странника,
деление слизней, деревни и рейды, снаряды и линия видимости у стрелков, способности боссов.
Внешний вид моделей — упрощённые типовые формы, в игре не проверялся.
