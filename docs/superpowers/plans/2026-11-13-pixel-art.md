# Pixel Art Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add selectable sharp 16×16 and 32×32 graphics to Voxium.
**Architecture:** pixel-art quantization transforms the existing 128px atlas and icons in memory; nearest GPU sampling avoids blur, settings persist and apply at game start.
**Tech Stack:** Rust 1.99.1, Bevy 0.20.1, image 0.25.
**Spec:** docs/superpowers/specs/2026-11-13-pixel-art-design.md

## Global Constraints
- Base is feature/minecraft-inventory-layout and existing Minecraft ZIP imports must work.
- 128 default preserves old appearance and original source PNG files.
- Settings take effect on **next launch** and UI says so.
- No world save format changes.

## Review Focus
- Existing 16×16 resourcepacks may be scaled up to 128 before quantization; they must remain sharp.
- Transparent pixels stay transparent with nearest resize.
- Layer border cannot smear into adjacent GPU material layers.
- Unknown pixel size in settings.cfg is recovered safely.
- 128×128 original mode is unchanged in all paths.
