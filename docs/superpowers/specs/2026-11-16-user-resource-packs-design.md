# Пользовательские ресурс-паки Voxium

Пользователь попросил заменить собак, скелетов, дракона, визера, домашних животных,
монстров, яйца призыва, GUI, текстуры блоков, шрифт и начальное меню присланными ресурсами.
Основа — PR #8, BASE-1, 19908c9. Два архива «База Алекса.zip» недоступны инструменту
передачи (>32 МиБ); их содержимое не считается изученным.

## Подход

Адаптировать ресурсы при сборке в родные данные Bevy: CEM-геометрия с иерархией,
локальными поворотами и UV; PNG без перерисовки; Faithful в существующий атлас с
сохранением ID и запасными тайлами для отсутствующих названий; растровый шрифт в TTF.
OptiFine в игре не требуется. Альтернатива — загрузчик всего формата OptiFine во время
игры — расширяет задачу на произвольные выражения, правила биомов и состояния Minecraft.
Замена только PNG на прежних моделях отвергнута: UV и силуэты не совпадают.

Приоритеты: Better Dogs для волка; отдельный Blue's Better Skeletons для скелета;
Boss Refreshed для дракона/визера; Better Farm Animals для перечисленных в паке видов;
Blue's Better Monsters для остальных поддержанных монстров. Spawned Eggs имеет приоритет
над Faithful для яиц. Colourful Containers имеет приоритет для контейнеров; Icons —
для значков меню. Остальные игровые правила и формат сохранений сохраняются.

Меню: название VOXIUM, читаемая тёмная панель поверх существующего пейзажа, одна основная
кнопка, создание/загрузка миров, настройки и выход; изображения Icons рядом с подписями.
Это выбранная исполнителем компоновка. Ширина и прокрутка должны сохранять доступность
кнопок при малом окне.

Проверка: конверсия координат/UV, прозрачных областей и иерархии; разрешение ресурсов;
формат атласа и кириллица; cargo fmt/check/clippy/test; фактический запуск при доступном
графическом окружении. Ограничения адаптации анимаций и отсутствующие ресурсы записать
в отчёт, не представлять их полной совместимостью OptiFine.
