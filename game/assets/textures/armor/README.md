# Исходные значки брони

Все 50 PNG из пользовательского `armor.zip` сохранены побайтно. `source-hashes.json` содержит SHA-256 архива и файлов. В 128x128, 64x64 и 32x32 — по 16 частей брони (leather, iron, golden, diamond × helmet, chestplate, leggings, boots). Общие атлас и таблица сохранены как оригиналы.

Все 16 предметов зарегистрированы по ID `survival:<имя файла>` и получают исходные PNG 128×128 в общем кеше значков. Слоты: helmet — голова, chestplate — грудь, leggings — ноги, boots — ступни. Экипировать их можно; защита, прочность и модель брони на персонаже пока не реализованы.

RGBA и полупрозрачные края сохраняются без поворота или обрезки, фильтрация линейная. Встроенный оригинал доступен без папки assets. Внешний `assets/textures/armor/128x128/<имя>.png` рядом с EXE или в текущем каталоге имеет приоритет после перезапуска. Повреждённый PNG или неверный размер даёт warning и возврат к оригиналу; при недоступности рисунка кеш использует процедурную заглушку.

Ограничение этапа 3 сохраняется: инвентарь и экипировка не восстанавливаются после закрытия мира.
