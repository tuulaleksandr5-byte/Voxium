# Исходные текстуры новых блоков

Файлы из пользовательского `voxel_textures (2).zip` распакованы с исходными путями, без изменения байтов, пересжатия или перерисовки. `source-hashes.json` содержит SHA-256 архива и всех 46 PNG и исходного `blocks_atlas_layout.ron`.

`128x128/`, `64x64/`, `32x32/` содержат по 15 граней: четыре руды, три блока ресурсов, четыре грани верстака и четыре грани печи. Общий атлас и его RON сохранены как оригиналы. Подключение граней и GPU-слоёв выполняется отдельно в задаче renderer mapping; исходные 17 PNG уровнем выше не изменены.

Runtime ID новых блоков: 17 coal_ore, 18 iron_ore, 19 gold_ore, 20 diamond_ore, 21 iron_block, 22 gold_block, 23 diamond_block, 24 crafting_table, 25 furnace. Строковые ID — `survival:<имя>`. Значки блоков остаются кубами из граней, а не изображениями из `icons/`.
