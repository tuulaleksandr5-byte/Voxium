# Исходные значки материалов

Все 49 PNG из `voxel_textures (2).zip` сохранены побайтно с исходными путями. SHA-256 архива и файлов — в `source-hashes.json`. В каждой из папок 128x128, 64x64 и 32x32 находится по 16 PNG; общий атлас сохранён как оригинал.

Клиент использует 128×128 `coal`, `raw_iron`, `raw_gold`, `iron_ingot`, `gold_ingot`, `diamond`, `leather` по ID `survival:<имя>`. Остальные девять PNG изображают блоки и сохраняются как исходные ресурсы; блоки в игре используют изометрические кубы из текстур граней.

Исходное RGBA, прозрачные поля и полупрозрачные края сохраняются при декодировании. Изображения встроены в EXE. Внешний `assets/textures/icons/128x128/<имя>.png` рядом с EXE или в текущем каталоге имеет приоритет. Повреждённый файл или размер, отличный от 128×128, даёт warning и возврат к встроенному оригиналу; при недоступности рисунка кеш использует прежнюю процедурную заглушку. После замены файла нужен перезапуск. Общий кеш используется в каталоге, хотбаре, курсоре и предметах мира; фильтрация линейная.
