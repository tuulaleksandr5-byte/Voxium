# Разработка Voxium

Текущая ветка `main` содержит **2.0.0-alpha.4** — рабочую, но незавершённую версию Survival 2.0. Начните с [README](../README.md), [навигации по документам](INDEX.md) и [дорожной карты](ROADMAP.md).

## Рабочий процесс

1. Создайте Issue с ожидаемым результатом, критериями готовности и затронутой подсистемой.
2. Создайте ветку от `main`, например `feature/core-ore-drops`, `fix/client-inventory` или `docs/readme-cleanup`.
3. Изменяйте минимум нужных файлов. Сохраняйте стабильные ID блоков, версии генератора и совместимость миров, если Issue явно не предусматривает миграцию.
4. Для изменений поведения добавьте или обновите автоматические тесты; UI и Windows проверяйте отдельно, когда это необходимо.
5. Запустите из корня репозитория:
   ```bash
   cargo fmt --all -- --check
   cargo check --workspace --locked
   cargo clippy --workspace --all-targets --locked -- -D warnings
   cargo test --workspace --locked
   ```
6. Откройте Pull Request. Укажите реально выполненные проверки, ограничения и влияние на существующие сохранения.

Не выдавайте незапущенные тесты за успешные. Не удаляйте исходные изображения, звуки и архивные инструкции без проверки, что они больше нигде не нужны. Сборку и выпуск игры оформляйте отдельно от рефакторинга документации.
