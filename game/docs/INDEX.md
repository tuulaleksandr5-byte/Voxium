## Структура проекта

```text
apps/client/          Игровой Bevy-клиент
crates/game_core/     Данные мира, физика, игровой процесс и сохранения
crates/game_render/   Геометрия и визуализация блоков
assets/               Текстуры, звуки, игровые конфигурации
docs/                 Документация и планы
tools/                Вспомогательные скрипты
.github/              Проверки CI и шаблоны GitHub
```

Не создавайте пустые crates из будущей архитектуры заранее. Не удаляйте `Cargo.lock`, `rust-toolchain.toml`, исходные ассеты и миграции сохранений ради «очистки» репозитория.
