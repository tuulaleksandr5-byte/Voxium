# Текстуры инструментов, материалов и брони

Пользовательские PNG сохранены побайтно, без пересжатия, поворота, обрезки или изменения RGBA. `assets/textures/tools/` содержит исходные 77 PNG; повторно присланный `tools (1).zip` совпадает с исходным `tools.zip`. `assets/textures/blocks/` и `icons/` сохраняют пути из `voxel_textures (2).zip`; `armor/` содержит оригиналы `armor.zip`. SHA-256 архивов и каждого файла записаны в `source-hashes.json` соответствующих папок. Прежние 17 текстур блоков не менялись.

Каталог содержит 25 инструментов: кирка, топор, лопата, мотыга, меч × дерево, камень, железо, золото, алмаз. Все доступны по ID `survival:<точное имя PNG>`, например `survival:golden_sword`; инструменты складываются по одному. Скорость добычи реализуется отдельной задачей обновления; боевые бонусы, обработка почвы и прочность пока не добавлены.

Все 16 частей брони (leather, iron, golden, diamond × helmet, chestplate, leggings, boots) получают исходные рисунки и принимаются соответствующими слотами экипировки. Защита, прочность и модель брони на персонаже пока не реализованы. Семь материалов с оригинальными PNG — coal, raw_iron, raw_gold, iron_ingot, gold_ingot, diamond, leather. Палка и яйцо сохраняют прежние процедурные значки: отдельного оригинального PNG палки в архивах нет.

Клиент декодирует отдельные PNG 128×128, сохраняя прозрачные поля и полупрозрачные края, и кеширует их один раз. Общий кеш используется каталогом, хотбаром, курсором и предметами мира с линейной фильтрацией. Блоки продолжают использовать изометрические кубы из текстур граней; плоские рисунки блоков из `icons/` не подменяют их. Подключение новых граней и GPU-слоёв относится к отдельной задаче renderer mapping.

Все используемые рисунки встроены в EXE. Внешний PNG по тому же пути `assets/textures/{tools,icons,armor}/128x128/<имя>.png` рядом с EXE или в текущем каталоге имеет приоритет после перезапуска. Повреждение или неверный размер даёт warning и возврат к встроенному оригиналу; при недоступности рисунка кеш использует процедурную заглушку. Без внешней папки assets работают встроенные изображения.

Ограничение этапа 3 сохраняется: инвентарь, экипировка, дроп и содержимое сундуков пока не восстанавливаются после закрытия мира. Полное завершение этапов 4–9 не заявляется.
