# Пользовательский референс добычи

`minecraft_mining_speed_1_20_1.txt` скопирован побайтно из пользовательского вложения. SHA-256 — в `mining-source-hashes.json`. Таблица задаёт точное время добычи для перечисленных сочетаний; разрешение дропа проверяется отдельно. Этот каталог хранит референс, реализация добычи следует отдельной задаче обновления.
